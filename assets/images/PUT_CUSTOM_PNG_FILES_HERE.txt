CUSTOM IMAGE ASSETS
-------------------
Replace the PNG files in this folder with your own PNG files, keeping the exact filenames:
  background.png  - scenery only (recommended 960x448; the game draws the ground separately)
  player.png      - character sprite (transparent background recommended)
  ring.png        - blood-red ring collectible
  emerald.png     - Chaos Emerald collectible
  shield.png      - Blood Shield collectible
  spike.png       - spike obstacle
  block.png       - block obstacle
  bat.png         - bat obstacle
  rock.png        - floating rock obstacle

The game automatically loads matching filenames. If a file is absent, its built-in drawing is used.
Keep PNG transparency for sprites. You can change paths in config.js if you prefer different names.
